# Lawde's Mart - Premium Supermarket System

A high-end, dark-themed supermarket web application built with Next.js, featuring a vibrant UI, bubbly animations, and real-time cart/checkout logic.

## 🚀 Features
- **Vibrant Dark Theme**: High-contrast UI with cyan/purple gradients.
- **Bubbly Animations**: Energetic logo and UI element transitions.
- **Real-time Storefront**: Browse products with category filtering and instant search.
- **Advanced Cart System**: Location-based delivery fee calculations (Ikotun, Ijegun, etc.).
- **Admin Portal**: Comprehensive dashboard for inventory and financial management.
- **Production Ready**: Optimized for hosting on Vercel.

## 🛠️ Technology Stack
- **Framework**: Next.js (App Router)
- **Styling**: Vanilla CSS with CSS Modules and Styled JSX.
- **Icons**: Lucide React.
- **Charts**: Recharts (for Admin Dashboard).
- **State Management**: React Context API with custom hooks.

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
